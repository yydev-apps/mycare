Setup Google Apps Script

  1. Buka fail Google Sheets baharu di Google Drive anda.
  2. Pergi ke menu Extensions > Apps Script.
  3. Padamkan semua kod sedia ada dan tampal (paste) kod berikut:
function doPost(e) {
  var sheet = SpreadsheetApp.getActiveSpreadsheet().getActiveSheet();
  var data = JSON.parse(e.postData.contents);
  sheet.appendRow([
    data.timestamp || new Date().toLocaleString('ms-MY'),
    data.nama || '',
    data.umur || '',
    data.jenis || '',
    data.bacaan || '',
    data.butiran || '',
    data.status || '',
    data.nota || ''
  ]);
  return ContentService.createTextOutput("OK").setMimeType(ContentService.MimeType.TEXT);
}
  1. Tekan butang Deploy > New deployment.
  2. Pilih jenis Web app.
  3. Setkan Who has access kepada Anyone (Penting!).
  4. Tekan Deploy, luluskan kebenaran, dan salin (copy) Web App URL yang terhasil ke ruangan Profil MyCare.
